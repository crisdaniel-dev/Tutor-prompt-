# AI Tutor Kit (linked lists in Python)

Use this at a computer without your files. No login needed on some free AI chatbots.

1. Open this repo on GitHub.
2. Open `01_TUTOR_PROMPT.md`, press **Raw**, select all, copy.
3. Paste it into the AI as your FIRST message. Wait for its short reply.
4. If the AI accepts long messages, also paste `02_REFERENCE_CODE.md` (tested code for all four lists).
5. Type what you want, for example: `teach add_before in doubly`, `mock`, `check this` + your code, or `full code`.

If the AI starts writing long answers or forgets your style, paste the prompt again.

The `code/` folder has the same tested code as separate files. In the exam your Node file is called `node.py` and the list file starts with `from node import Node`. In this repo the imports are `from node_singly_circular import Node` and `from node_doubly import Node` so both Node versions can sit in one folder.
